# 1.7B 学生 Skywork 数据重训练计划

> 日期：2026-08-14 ｜ 目标：训练数据从默认/GSM8K 换成论文 Skywork-OR1 math 后，
> 重新训练 Qwen3-1.7B 学生，**保持/超过此前 ms_17b 的健康收敛轨迹**（E[Δ_T] 0.013→0.060
> 单调上升、step120 最优、AIME 短生成 13.3%/16.7%）。
> 约束：单卡 RTX PRO 6000 96GB（服务器恢复后执行）；transformers 原生（非 vLLM）。

## 背景与关键约束（探索结论）

1. **此前 ms_17b 健康收敛超参**（服务器实测，必须复用）：
   `lr=3e-5`、`kl_reg_coef=0.5`、`delta_clip=2.0`、`top_k_teacher/student=256`、
   `renormalize_topk_support=true`、`batch_size=8`、`n_steps=200`（step120 最优、step199 过训）、
   `dtype=bf16`、`cache_mode=topk`、`warmup_M=0`（L0）。
2. **HFCausalLM 无 `generate_batch` 方法**（model_factory.py 只有 response_dists）->
   Stage1 warmup（student_init）在 HF 路径下会 AttributeError，**这是此前用 L0 的根因**。
   → 本计划用**外部脚本预生成 response** 填入 jsonl，绕过此限制（见阶段 0.4）。
3. **JsonLinesDataLoader 要求 prompt+response 都非空**（data.py 跳过空 response 行）。
   Skywork 原始只有 prompt+ground_truth，**必须预生成 response**。
4. **prepare_skywork_math.py 输出 parquet**（DAPO prompt + gt），JsonLinesDataLoader 读 jsonl
   → 需额外 parquet→jsonl + 子集采样 + response 预生成三步。
5. **教师对**：1.7B 用 JustRL-DeepSeek-1.5B（teacher_rl）/ DeepSeek-R1-Distill-Qwen-1.5B
   （teacher_ref），同 R1/Qwen2.5 家族（已下载，服务器 models/ 目录）。
6. **model_kind=hf 跳过 Stage0 RL**，直接用预下载教师对（pipeline.py _stage0_teachers）。

```bash
cd /root/opd
python Direct-OPD/scripts/prepare_skywork_math.py \
  --input /root/autodl-tmp/datasets/skywork/data/math-00000-of-00001.parquet \

# 输出：每行 prompt=[{role:user, content: DAPO包装题}], reward_model.ground_truth
```

### 0.3 parquet → jsonl + 10K 子集采样
新脚本 `main/scripts/prepare_skywork_jsonl.py`：
- 读 DAPO parquet，提取 `prompt[0].content`（已是 DAPO 模板文本）+ `ground_truth`
- 随机采样 **10,000 条**（seed=42 可复现）
- 输出 jsonl，每行 `{"prompt": <DAPO文本>, "response": "", "ground_truth": <ans>}`
  （response 暂空，下一步填）
- **校验**：10K 行、prompt 非空、ground_truth 非空

### 0.4 response 预生成（关键，绕过 HFCausalLM 无 generate_batch）
新脚本 `main/scripts/prepare_skywork_responses.py`：
- 加载初始 Qwen3-1.7B（`AutoModelForCausalLM`，bf16，**启用 flash_attn**）
- 对 10K 条 prompt 逐批 `model.generate`（transformers 原生，非 pipeline 内部）：
  - `max_new_tokens=2048`（对齐论文 `MAX_RESP_LENGTH`，训练 response 长度）
  - `temperature=1.0`、`do_sample=True`（on-policy 初始分布，对齐论文 warmup 语义）
  - `batch_size=8`（控显存），逐题即时落盘 + resume（复用 eval_aime 的 progressive 模式）
- 把生成的 response 文本写回 jsonl 的 `response` 字段
- **校验**：10K 条 response 非空、平均长度合理（非全截断）
- 预估耗时：10K × 2048 token，1.7B bf16+flash ~50 tok/s -> ~1.1 小时（可 resume 分段）

### 0.5 数据校验
- jsonl 10,000 条，prompt/response/ground_truth 三字段非空
- 用 Qwen3-1.7B tokenizer 试编码，`max_prompt_len=1024`/`max_response_len=2048` 下截断率 <5%
- 产物路径：`/root/autodl-tmp/datasets/skywork_10k.jsonl`

```yaml

  response_key: response
  max_prompt_len: 1024            # 对齐论文 MAX_PROMPT_LENGTH

stage1:
  enforce_teacher_consistency: true

  warmup_M: 0                     # L0（HF 无 generate_batch；L1 见"可选增强"）
  warmup_source: none

stage2:

  staleness_threshold: 4
  queue_size: 8

  renormalize_topk_support: true  # 对齐原始 Direct-OPD
```

**关键超参决策依据**：
- `lr=3e-5`/`kl=0.5`/`delta_clip=2.0`：ms_17b 实测健康收敛的三大护栏，**不可用默认值**（默认 lr=1e-3 会爆、kl=0.05 会塌陷）。
- `n_steps=200`+`checkpoint_every=20`：复现 step120 最优 + 监测过训。
- `warmup_M=0`（L0）：HF 路径限制。如要 L1 缓解曝光偏差，见"可选增强"。

### 2.3 收敛监控判据（逐 checkpoint 检查 metrics.csv）
| 指标 | 健康范围 | 异常处置 |
|------|---------|---------|
| `E[Δ_T]`（adv_mean） | 单调上升，step120 达 +0.04~0.06 | 若停滞/下降 -> 检查 delta_clip/kl |
| `loss` | 稳定在 -0.2~-0.5，无 >10 爆炸 | 爆炸 -> 降 lr/加 delta_clip |
| `kl_loss` | 0.5~1.5，不坍缩到 0 | 坍缩 -> 加 kl_reg_coef |
| `age`（staleness） | >0（异步消费陈旧样本） | 恒 0 -> 异步未生效 |
| step120 AIME | ≥ 此前 13.3%/16.7%（短生成） | 显著低 -> 数据/超参问题 |

### 2.4 早停策略
- 每 20 步存 checkpoint，**step100/120/140 三个断点必做 AIME 评估**
- 若 step120 后 E[Δ_T] 连续下降 -> 早停于 step120（复现此前最优）
- 若 step120 仍在上升 -> 延长到 step200，找新最优点

## 可选增强：L1 warmup（缓解曝光偏差）

当前 L0（warmup_M=0）因 HFCausalLM 无 generate_batch。若要开 L1：
- **方案 A（推荐）**：阶段 0.4 预生成时每条 prompt 生成 **M+1 条 response**（M=4），
  拼成 10K×5=50K 条胖 D jsonl，Stage1 直接读（warmup_M=0 但数据已含多样 response）。
  相当于"离线 L1"，零代码改动。
- **方案 B**：给 HFCausalLM 补 `generate_batch` 方法（调 transformers generate），
  然后 warmup_source=student_init。改动 model_factory.py，需测试。

建议先用方案 A（L0 + 预生成多 response）跑通，再视收敛情况决定是否上 B。

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| Skywork response 预生成耗时长 | 逐题落盘 + resume（复用 eval_aime progressive）；flash_attn 加速 |
| 初始 student response 质量差（1.7B 未训练） | on-policy 对齐论文；Δ_T 信号来自教师对（与 response 质量弱相关） |
| 过训（step199 跌落） | checkpoint_every=20 + step100/120/140 评估 + 早停 |
| Δ_T 爆炸（Skywork 真实词表） | delta_clip=2.0 + top_k=256 稀疏 |
| 显存（10K 条 cache） | topk 缓存 ↓1000× + offload_to_cpu |
| 单卡训练+评估不能并行 | 训练完再评估（串行） |

## 验收标准

1. **数据**：skywork_10k.jsonl 10K 条，prompt/response/ground_truth 非空，token 化合规
2. **训练**：200 步跑完，E[Δ_T] 单调上升至 +0.04~0.06，loss 无爆炸
3. **收敛**：step120 附近 AIME ≥ 此前 13.3%/16.7%（短生成），或长生成 ave@8 有提升
4. **对比**：post（训练后）> pre（基座）AIME 分数
