## 5. 根因链最终判定

| 根因 | 判定 | 证据 |
|---|---|---|
| **RC1 固定 D**（偏离论文 on-policy） | **结构性成立** | E-0d：on-policy（refresh）仅 3.7%，96.3% 静态 base 重放 |
| **RC2 代理门控**（eval_reward 选 KL/判通过） | **成立** | kl=0.02 由 eval_reward 代理指标挑出（+0.51），下游未受益 |
| **RC3 弱 KL + 500 样本重放过拟合** | **成立** | E-0c：step_200 后大幅劣化（0.406→0.288），早停可缓解 |
| **RC4 Δ 语义**（与正确性脱钩） | **弱信号（非方向错误）** | E-1b ρ=0.1765（>0 有语义但强度不足）；教师对正常（rl 更强） |
| RC5 工程近似（delta_clip/top-K/pad_id） | 噪声 | 不改变方向性结论 |

**机制定稿**：训练用固定 500 条 base 轨迹上的 Δ 缓存（on-policy 占 3.7%），弱 KL（0.02）允许大幅漂移 → 学生把固定支撑的逐状态分布 sharpen 到缓存的 Δ 模式上（eval_reward +0.51 是代理假象）→ 生成分布被扭曲为**更长推理但无正确性绑定**（avg_rt 4303→6069-6565，AIME24 全截断全 0）。ρ=0.1765 表明 Δ 带弱正确性语义，但**强度不足以在漂移下保持能力**。

## 6. 复现失败结论（诚实记录）

1. **OPD 复现未成功**：所有协议/预算下学生 ≤ Base；B8192@3 majority 最干净口径下显著落后。
2. **唯一正面信号**：B512 chat 学生反超 Base（0.110/0.114 vs 0.082）——短预算下相对提升，但这是被截断的相对优势（B512 全截断），无能力意义。
3. **评估协议教训**：
   - 旧裸 prompt B512（Base=0.344）与旧 AIME24 结果**全部作废**（协议假象）；
   - **eval_reward（固定集 E[Δ_T]）是代理指标**，不能作为能力判据（符号反转：+0.51 与 −0.44 同时成立）；
   - **评估预算必须充分**（B2048 对教师是截断域；B8192@3 才基本释放）且多数投票稳健。
4. **训练纪律教训**：固定数据 + 弱 KL + 代理门控的组合可制造"信号上升但能力下降"的假象；判据必须用下游指标（B8192@3 majority）。

## 7. 修复方向建议（供未来决策，本轮不执行）

按归因链，若继续 OPD 方向，建议组合修复（优先级排序）：

1. **A1 on-policy 化**：refresh 变主食（refresh_min_interval=1~2、m_refresh=batch），静态池只做前 N 步 warmup——回到论文 on-policy 语义，L2 基建已在。
2. **B2 信号改造**：`reward = α·correct + β·Δ_seq`（答案导向加权），退化到教师先验加权的 RAFT/最优-n 蒸馏。
3. **非截断域信号**：在 B8192 教师分布上计算 Δ（当前 500 条 base B2048 轨迹对 JustRL 是截断域）。
4. **判据**：一切训练通过判据换下游指标（B8192@3 majority，训练中用 100 题子集快速版每 50 步）；eval_reward 降级为漂移报警器。
5. **止损线**：任何分支先跑 120 步，下游 100 题子集不升即停。
